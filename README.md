# rain_garden_remote_telemetry
Working with Alena Brayshaw @ Rutgers Cooperative Extension Water Resources Program to develop efficient remote telemetry for rain gardens in New Jersey

See documentation/general/Hardware Notes.pdf for project specifics on hardware used, especially the SIM7000. See documentation/general/components for component-specific datasheets, most of which are also generally available online.

See src/main.cpp for the arduino code.
